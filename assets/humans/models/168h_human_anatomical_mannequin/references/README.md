# Graphical correction source

makehuman/ contains official MakeHuman hm08 base.obj, default.mhskel joint measurements, default_weights.mhw and full CC0 asset notices from the exact commit pinned in provenance.json. These are graphical data, not upstream program logic. Only the body OBJ face group is included in the mannequin; helper models are excluded. The output skeleton is our existing V1, not MakeHuman's hierarchy. Original adapter code is authored in this repository. CC0 on upstream data does not silently select the project's artwork release terms or make all artwork MIT.
